# Голос автора: профиль по реальным постам

Задача навыка: разобрать 5–20 реальных постов пользователя и собрать короткий профиль голоса. Навык `post-telegram` потом пишет черновики по этому профилю. Профиль описывает, как человек пишет на самом деле, а не как ему хотелось бы.

## Шаг 1. Собрать образцы

Если пользователь вызвал навык без постов, не отвечай общими словами. Скажи прямо: «Вставьте прямо сюда, в этот чат, 5–20 своих постов» и дай два способа их достать из навыка `start` (шаг 2): скопировать вручную или выгрузить канал через Telegram Desktop.

Попроси у пользователя 5–20 своих постов. Подойдут:

- текст, вставленный прямо в чат;
- файл с выгрузкой канала (Telegram Desktop умеет выгружать историю в HTML или JSON);
- ссылки на посты, если в сессии есть инструмент для чтения веб-страниц.

Если постов меньше пяти, всё равно составь профиль, но пометь его как предварительный и предложи дополнить позже. Не выдумывай черты, которых нет в образцах.

Отдельно спроси одним сообщением, если это не видно из постов:

1. О чём канал и для кого он.
2. На «ты» или на «вы» обращается к читателю.
3. Какие слова или приёмы автор терпеть не может в чужих текстах.

## Шаг 2. Разобрать образцы

Пройди по каждому пункту из `references/chto-razbirat.md` и опирайся на цитаты из постов. Каждое правило профиля должно иметь хотя бы один пример из текстов автора. Правило без примера не попадает в профиль.

Особое внимание:

- **Структура поста.** Как начинается (сцена, тезис, цифра, вопрос), как устроен поворот мысли, чем заканчивается.
- **Ритм.** Средняя длина предложения и абзаца, есть ли короткие абзацы-паузы.
- **Лексика.** Любимые связки, разговорные слова, словечки-маркеры. Что автор не использует никогда.
- **Позиция.** Эксперт сверху, практик в процессе, скептик, рассказчик.
- **Оформление.** Эмодзи, жирный, курсив, списки, хэштеги.

## Шаг 3. Собрать профиль

Заполни шаблон из `references/shablon-profilya.md`. Держи профиль коротким: 300–700 слов. Длинный профиль размывает главное.

Покажи профиль пользователю целиком и спроси, что не так. Поправь по его ответу.

## Шаг 4. Сохранить профиль

Предложи пользователю сохранить профиль, чтобы не собирать его заново:

- Если сессия привязана к проекту Claude, предложи добавить профиль в материалы проекта. Это лучший вариант: профиль будет доступен в любом чате проекта.
- Если проекта нет, посоветуй создать его (например, «Мой канал») и положить профиль туда.
- Если в сессии открыта рабочая папка, можно сохранить файл `golos-avtora.md` в неё. Навык `post-telegram` ищет файл с этим именем.
- Иначе отдай профиль текстом и посоветуй хранить его и вставлять в чат перед просьбой написать пост.

Объясняй простыми словами, без терминов вроде «markdown» и «рабочая директория».

Сохраняй файл только с согласия пользователя и только туда, куда он указал. Навык никуда не отправляет тексты пользователя.

## Обновление профиля

Когда пользователь правит черновик, сравни свою версию с его финальной. Если правка показывает устойчивую черту голоса (заменил слово, убрал приём, поменял концовку), предложи одной строкой добавить это в профиль. Не обновляй профиль молча.

## Чего не делать

- Не приписывай автору черты, которых нет в его постах.
- Не превращай профиль в общие советы по копирайтингу. Профиль описывает конкретного человека.
- Не цитируй в профиле личные данные третьих лиц из постов.
